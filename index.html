06Help
Questions before you install

    

      How do I install Nexus on a Mac?
      
Pick Apple Silicon if your Mac has an M1, M2, M3 or M4 chip (Apple menu > About This Mac), otherwise Intel. Open the downloaded file and drag Nexus into Applications. The Mac version is not yet registered with Apple, so the first time, right-click Nexus in Applications and choose Open, then Open again. When a new version is ready, Nexus downloads it and shows Update now; drag the new Nexus into Applications and choose Replace. SunPass logins on a Mac are kept in your Mac's Keychain.

    

    

      Windows shows a warning when I open the installer. What do I do?
      
The Nexus installer is digitally signed, and Windows lists the verified publisher as Sarah Wesner. Because the signature is new, Windows SmartScreen may still show "Windows protected your PC" for a while. If it does, check that the publisher is Sarah Wesner, then choose More info and Run anyway.

      
If Smart App Control blocks it, ask the Nexus team before changing any Windows security settings.

    

    

      Do I need administrator rights?
      
No. Nexus installs into your own Windows account, so you can install it without an administrator.

    

    

      How do updates work?
      
Nexus checks for new versions every few minutes and downloads them in the background. Small updates arrive within minutes and are applied the next time Nexus restarts; your settings and account data are always kept. The installer you download here updates itself to the newest version the first time it opens.

    

    

      Can anyone use Nexus?
      
Anyone can install it, but Nexus only shows agency data after you sign in with an Everything Medicare login created by the Nexus owner. What you see depends on the role on that login: Managers get the manager home page, built around the numbers they check every day, plus the current SunPass codes. If the owner removes a login, it stops working on every computer the next time it signs in.

    

    

      Why does Nexus ask for an access code?
      
Each access code is made for one person and opens Nexus on one computer. Nexus asks for it the first time it opens, and again any time Nexus is uninstalled and reinstalled. Updates never ask for a code. If your login was re-created, ask the Nexus owner for a new code and choose Enter a newer access code on the sign-in screen.
